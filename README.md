# GitHub User Activity Console App

This is a simple console application that interacts with the GitHub API to fetch and display user activity events.

## Features

- Fetches user activity events from GitHub.
- Displays different types of events such as Push, Issues, Watch, Fork, and Create.

## Prerequisites

- Node.js installed on your machine.
- A GitHub account.

## Installation

1. Clone the repository:
  ```sh
  git clone https://github.com/iAndres-T/Github-User-Activity.git
  ```
2. Navigate to the project directory:
  ```sh
  cd github-user-activity
  ```
3. Install the dependencies:
  ```sh
  npm install
  ```

## Usage

1. Run the application:
  ```sh
  node index.js
  ```
2. Enter the GitHub username when prompted.

## Dependencies

- [axios](https://www.npmjs.com/package/axios) - Promise based HTTP client for the browser and node.js.
- [dotenv](https://www.npmjs.com/package/dotenv) - Loads environment variables from a .env file into process.env.
- [readline-sync](https://www.npmjs.com/package/readline-sync) - Synchronous Readline for interactively running to have a conversation with the user via a console.
